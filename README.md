# World's Greatest Composers — Piano For ALL

Bilingual (English / Myanmar), responsive iOS-inspired music education website.

## Current implementation
- Eight historical eras from ancient traditions through contemporary music.
- 22 short composer profiles and representative works.
- Ten introductory music-theory lessons.
- Interactive ten-question quiz, immediate feedback, local learning progress.
- Language toggle, search/filter, dedicated academic references page.
- Static and offline-capable once loaded; no login, tracking or third-party scripts.

## Run
Open `index.html` in a browser or run `python3 -m http.server 5500` locally.

## Academic references
- Open Music Theory: https://viva.pressbooks.pub/openmusictheory/
- Understanding Music: Past and Present: https://oer.galileo.usg.edu/arts-textbooks/1/
- Yale Listening to Music: https://oyc.yale.edu/music/musi-112
- Grove Music Online: https://www.oxfordmusiconline.com/
- Britannica: https://www.britannica.com/art/classical-music
- IMSLP: https://imslp.org/

These are background references, not evidence of line-by-line verification. Historical dates and stylistic period boundaries are approximate. Do not copy protected textbook text, recordings, or score editions without rights clearance.

## Honest scope
This is a **working starter edition**, not a complete conservatory/university curriculum. Comprehensive scholarly biographies, advanced harmony/counterpoint, ear training, notation playback, audio licensing, account sync, accessibility audits, and native iOS packaging remain future work.
